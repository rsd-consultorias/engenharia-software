## Checklist de Etapas e Entregáveis - Cascata/Tradicional

### 1. Levantamento de Requisitos
- **Tarefas**:
  - [ ] Reunir informações dos stakeholders.
  - [ ] Definir claramente os requisitos funcionais e não funcionais.
- **Entregáveis**:
  - [ ] Documento de Requisitos de Software (SRS).
  - [ ] Diagramas de casos de uso.

### 2. Análise de Sistema
- **Tarefas**:
  - [ ] Analisar requisitos para identificar viabilidade técnica.
  - [ ] Criar modelos de sistema.
- **Entregáveis**:
  - [ ] Modelos UML (Diagramas de Classe, Sequência).
  - [ ] Documento de Especificação Técnica.

### 3. Design do Sistema
- **Tarefas**:
  - [ ] Criar a arquitetura do sistema.
  - [ ] Definir design de banco de dados e interface de usuário.
- **Entregáveis**:
  - [ ] Documento de Design Arquitetural (ADD).
  - [ ] Protótipos de interfaces.
  - [ ] Modelos de dados.

### 4. Implementação
- **Tarefas**:
  - [ ] Codificar de acordo com os requisitos e design.
  - [ ] Realizar revisões de código.
- **Entregáveis**:
  - [ ] Código-fonte completo.
  - [ ] Scripts de configuração.

### 5. Testes
- **Tarefas**:
  - [ ] Testar cada componente individualmente (testes unitários).
  - [ ] Executar testes de integração e sistema.
- **Entregáveis**:
  - [ ] Casos de teste e resultados.
  - [ ] Relatório de bugs corrigidos.

### 6. Implantação
- **Tarefas**:
  - [ ] Configurar ambientes de produção.
  - [ ] Publicar a aplicação no ambiente definido.
- **Entregáveis**:
  - [ ] Aplicação implantada.
  - [ ] Documentação de implantação.

### 7. Manutenção
- **Tarefas**:
  - [ ] Corrigir bugs relatados.
  - [ ] Implementar melhorias futuras.
- **Entregáveis**:
  - [ ] Logs de manutenção.
  - [ ] Relatórios de patches e atualizações.
